# Pro 2. publish.sh — настоящий скрипт публикации

**Что делаем:** собираем в один скрипт всё, что делали руками в заданиях
6–14: упаковка, загрузка, проверка результата.

## Задание

Откройте `publish.sh`. ВПИШИТЕ три пропуска:

1. пароль;
2. команду упаковки каталога `myapp` в архив (задание 6);
3. HTTP-код успешной загрузки (подсказка: вы видели его в задании 14,
   и это не 200).

## Проверка

```bash
chmod +x publish.sh
./publish.sh 1.1.0
```

Должно напечатать «Опубликовано». А теперь намеренно испортите пароль
и запустите ещё раз: скрипт обязан честно написать про ошибку и выйти
с ненулевым кодом (`echo $?` — должно быть 1). Верните пароль.

## Бонус (необязательно)

Добавьте в конец обратное скачивание и сверку sha256 (задания 9–10) —
тогда скрипт сам доказывает, что артефакт доехал целым.
