# Лабораторная работа: JFrog Artifactory

**Что делаем:** поднимаем свой менеджер артефактов и учимся работать
с ним из командной строки: публиковать, скачивать, проверять,
автоматизировать.

## Как работать

1. Задания лежат в папках `task01-...` … `task15-...`.
   Выполняйте **по порядку** — каждое опирается на предыдущее.
2. В каждой папке свой `README.md` с подробными шагами. Команды даны
   целиком; иногда есть пропуск `____` или пометка **ВПИШИТЕ** — туда
   подставьте своё значение (пароль, версию, одно слово).
3. `pro01`…`pro10` — задания повышенной сложности для тех, кто закончил
   базу. Там скрипты дописываются самостоятельнее.
4. По каждому заданию в конце написано, что сдать в отчёт
   (скриншот или вывод команды).

## Подготовка

```bash
git clone <ссылка-на-репозиторий>
cd artifactory-lab-students
```

Дальше — в `task01-run/README.md`.

## Карта заданий

**Базовый уровень**

| Папка | Тема |
|---|---|
| `task01-run` | Запуск стенда |
| `task02-health` | Проверка готовности |
| `task03-login` | Вход в интерфейс, смена пароля |
| `task04-repo-ui` | Создание репозитория в интерфейсе |
| `task05-repo-api` | Список репозиториев через API |
| `task06-build-app` | Приложение и архив |
| `task07-upload` | Публикация артефакта |
| `task08-ui-artifact` | Артефакт в интерфейсе |
| `task09-download` | Скачивание |
| `task10-verify` | Проверка целостности (sha256) |
| `task11-new-version` | Выпуск версии 1.0.1 |
| `task12-file-info` | Паспорт артефакта через API |

**Про-уровень**

| Папка | Тема |
|---|---|
| `pro01-cleanup` | Retention: чистка старых версий |
| `pro02-publish` | Полноценный скрипт публикации |
| `pro03-deploy` | Скрипт деплоя последней версии |
| `pro04-permissions` | Права доступа |
| `pro05-secrets` | Пароли вне кода (env, .netrc) |

| `pro08-promotion` | Promotion: из dev в прод |

## Оценка

- task01–task15 — «удовлетворительно»;
- база + любые четыре из pro — «хорошо»;
- база + все pro — «отлично».

## Если что-то не работает

- Стенд долго стартует — нормально до 3–7 минут: `docker compose logs -f`.
- `401 Unauthorized` — не тот пароль (нужен заданный при первом входе).
- `400 ... Artifactory Pro` — функция только в платной версии, нормально.
- Начать заново: `docker compose down -v && docker compose up -d`.
