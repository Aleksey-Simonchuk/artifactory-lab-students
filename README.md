# Лабораторная работа: JFrog Artifactory

**Что делаем:** поднимаем свой менеджер артефактов и учимся публиковать
в него файлы из командной строки.

## Как работать

1. Задания лежат в папках `tasks/task01-...`, `tasks/task02-...` и т.д.
   Выполняйте их **по порядку** — каждое опирается на предыдущее.
2. В каждой папке свой `README.md` с шагами. Большинство команд даны
   целиком — их нужно просто выполнить.
3. Иногда в команде или скрипте есть пропуск, помеченный `____` или словом
   `ВПИШИТЕ` — туда нужно подставить своё значение (пароль, версию,
   одно слово). Всё остальное уже написано за вас.
4. Папка `pro/` — задания повышенной сложности для тех, кто справился
   с основной частью. Там скрипты нужно дописывать самостоятельнее.
5. По каждому заданию сохраняйте доказательство выполнения (скриншот или
   вывод команды) — список для отчёта в конце этого файла.

## Подготовка (один раз)

```bash
git clone <ссылка-на-репозиторий>
cd artifactory-lab-students
```

Дальше — в `tasks/task01-start/README.md`.

## Карта заданий

| Папка | Тема |
|---|---|
| `tasks/task01-start` | Запуск стенда |
| `tasks/task02-repo` | Вход в интерфейс, свой репозиторий |
| `tasks/task03-upload` | Первая публикация артефакта |
| `tasks/task04-download` | Скачивание и проверка целостности |
| `tasks/task05-new-version` | Выпуск новой версии |
| `tasks/task06-file-info` | Информация о файле через API |
| `tasks/task07-checksum` | Загрузка с проверкой контрольной суммы |
| `tasks/task08-aql` | Поиск по хранилищу (AQL) |
| `pro/pro01-cleanup` | Скрипт чистки старых версий |
| `pro/pro02-publish` | Скрипт публикации |
| `pro/pro03-deploy` | Скрипт деплоя |
| `pro/pro04-permissions` | Права доступа |

## Оценка

- задания 1–8 — «удовлетворительно»;
- 1–8 + любые два из `pro/` — «хорошо»;
- всё — «отлично».

## Отчёт

Сдайте: скриншот входа в UI (1), список репозиториев (2), JSON ответа на
загрузку (3), совпавшие sha256 (4), две версии в UI (5), команду-конвейер (6),
коды 201 и 409 (7), AQL-запрос (8), скрипты и их вывод (pro).

## Если что-то не работает

- Стенд долго стартует — нормально до 3–7 минут: `docker compose logs -f`.
- `401 Unauthorized` — не тот пароль (нужен тот, что задали при первом входе).
- `400 ... Artifactory Pro` — функция только в платной версии, это нормально.
- Начать заново: `docker compose down -v && docker compose up -d`.
