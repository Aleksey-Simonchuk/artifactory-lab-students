# Pro 3. deploy.sh — скрипт деплоя

**Что делаем:** вторую половину пайплайна. Сервер сам находит в Artifactory
**последнюю** версию и разворачивает её.

**Зачем:** сервер не знает номеров версий заранее — он спрашивает
у хранилища «что сейчас последнее» и забирает это.

## Задание

Откройте `deploy.sh`. Список версий уже получается и сортируется.
ВПИШИТЕ два пропуска:

1. как у отсортированного списка взять **последнюю** строку
   (`head` берёт первые, а что берёт последние?);
2. команду распаковки архива (в задании 6 вы *паковали* — теперь наоборот;
   флаги `c`/`z`/`f` уже знакомы, какой флаг распаковывает?).

## Проверка

```bash
chmod +x deploy.sh
./deploy.sh
```

Скрипт должен найти последнюю версию, распаковать её в `deploy/`
и вывести содержимое `deploy/VERSION`.

Проверьте связку: опубликуйте новую версию скриптом из pro02,
снова запустите `./deploy.sh` — развернулась именно она?

## Результат

**В отчёт:** скрипт и вывод двух запусков подряд (до и после публикации
новой версии).
