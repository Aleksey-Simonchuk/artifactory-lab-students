# Pro-задание 1. cleanup.sh — чистка старых версий

**Цель:** написать скрипт, который оставляет в репозитории только 2 последние
версии myapp, остальные удаляет.

## Подготовка

Опубликуйте версии 1.0.0–1.0.4 (меняйте `VERSION` в `upload.sh` из задания 3
и запускайте его).

## Задание

Откройте `cleanup.sh` — каркас готов: получение списка версий и их сортировка
уже написаны. ВПИШИТЕ пропуски: пароль и HTTP-метод удаления
(вспомните таблицу методов из презентации).

Запустите и проверьте в UI: должны остаться только `1.0.3` и `1.0.4`.

## Результат

В отчёт: готовый скрипт и вывод его работы.
