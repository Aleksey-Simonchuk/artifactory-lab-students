# Pro-задание 3. deploy.sh — скрипт деплоя

**Цель:** написать вторую половину пайплайна: сервер сам находит последнюю
версию в Artifactory и «разворачивает» её.

## Задание

Откройте `deploy.sh`. Список версий уже получается и сортируется.
ВПИШИТЕ два пропуска:

1. как у отсортированного списка взять **последнюю** строку
   (вспомните `head`/`tail`);
2. команду распаковки архива в каталог (вы паковали — теперь наоборот).

Проверка: `./deploy.sh` должен распаковать последнюю версию в `deploy/`
и вывести содержимое `deploy/VERSION`.

Пара `publish.sh` (pro02) + `deploy.sh` — это мини-CI/CD: один скрипт
публикует, другой забирает.

## Результат

В отчёт: готовый скрипт и вывод `./deploy.sh`.
