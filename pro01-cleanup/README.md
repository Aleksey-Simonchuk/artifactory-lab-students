# Pro 1. Retention: чистка старых версий

**Что делаем:** скрипт, который оставляет только 2 последние версии myapp,
остальные удаляет.

**Зачем:** хранилище не резиновое. В проде действуют правила retention:
«храним N последних версий, остальное удаляем».

## Подготовка

Опубликуйте версии 1.0.0–1.0.4 (повторите задание 11 с разными версиями).

## Задание

Откройте `cleanup.sh`. Получение и сортировка списка версий уже написаны.
ВПИШИТЕ два пропуска:

1. пароль;
2. HTTP-метод, которым удаляют ресурс (таблица методов — в `slides.html`).

Запустите, затем проверьте список версий командой:

```bash
curl -s -u admin:ВАШ_ПАРОЛЬ \
  http://localhost:8081/artifactory/api/storage/myapp-local/myapp/ | grep uri
```

## Результат

Остались только `1.0.3` и `1.0.4`.

**В отчёт:** скрипт и вывод проверочной команды.

> На macOS `head -n -2` не работает — поэтому количество строк
> считается через `$((total - KEEP))`. Разберите этот приём.
