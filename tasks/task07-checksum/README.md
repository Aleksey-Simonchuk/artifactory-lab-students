# Задание 7. Загрузка с проверкой контрольной суммы

**Цель:** заставить Artifactory проверять файл прямо при загрузке.

Если при загрузке передать заголовок `X-Checksum-Sha256`, сервер сверит
сумму полученного файла с переданной. Не сошлась — файл не будет принят.

## Шаги

1. Выполняйте из папки `tasks/task03-upload`. Посчитайте сумму архива:

```bash
shasum -a 256 myapp-1.0.1.tar.gz
```

2. Откройте файл `checked-upload.sh` в этой папке, ВПИШИТЕ пароль
   и посчитанную сумму. Запустите:

```bash
./checked-upload.sh
```

Загрузка должна пройти успешно.

3. А теперь сломайте проверку: замените в `checked-upload.sh` сумму
   на `0000` и запустите ещё раз.

## Результат

Первая загрузка — код `201`, вторая — `409` и ошибка про checksum в ответе,
файл по пути `1.0.1-checked` НЕ появляется. В отчёт: оба кода ответа.

> Именно так в настоящих пайплайнах ловят битые файлы при передаче по сети.
