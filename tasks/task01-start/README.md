# Задание 1. Запуск стенда

**Цель:** поднять Artifactory и убедиться, что он работает.

## Шаги

1. Убедитесь, что Docker запущен:

```bash
docker version
```

2. Из корня репозитория (там, где лежит `docker-compose.yml`) запустите стенд:

```bash
docker compose up -d
```

Поднимутся два контейнера: `artifactory` и `artifactory-postgres`
(Artifactory хранит данные в базе PostgreSQL — посмотрите в
`docker-compose.yml`, как они связаны).

3. Дождитесь готовности — первый запуск занимает 3–7 минут. Проверка:

```bash
curl http://localhost:8082/router/api/v1/system/health
```

Пока сервис не готов, будет ошибка соединения или код 503. Когда всё
поднялось — придёт JSON и код 200. Можно повторять команду раз в полминуты.

4. Откройте в браузере http://localhost:8082 — должна появиться страница
входа JFrog.

## Результат

В отчёт: скриншот страницы входа или вывод health-проверки с кодом 200.
