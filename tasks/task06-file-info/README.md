# Задание 6. Информация о файле через API

**Цель:** получить «паспорт» артефакта и достать из него контрольную сумму
одной командой-конвейером.

## Шаги

1. Запросите информацию о файле (ВПИШИТЕ пароль):

```bash
curl -u admin:____ \
  http://localhost:8081/artifactory/api/storage/myapp-local/myapp/1.0.0/myapp-1.0.0.tar.gz
```

Посмотрите на JSON: размер, кто и когда загрузил, контрольные суммы.

2. Теперь откройте файл `info.sh` в этой папке. Команда почти готова,
   но в `grep` пропущено слово — ВПИШИТЕ, какое поле мы ищем
   (подсказка: самая надёжная контрольная сумма из трёх).
3. Запустите: `./info.sh`

## Результат

На экране — только само значение sha256, без лишнего JSON.
В отчёт: готовую строку из `info.sh`.
