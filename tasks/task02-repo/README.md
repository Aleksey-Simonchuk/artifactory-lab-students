# Задание 2. Вход в интерфейс и свой репозиторий

**Цель:** войти в Artifactory, сменить пароль, создать репозиторий
`myapp-local`.

## Шаги

1. Откройте http://localhost:8082 и войдите: логин `admin`, пароль `password`.
2. Мастер первичной настройки предложит задать новый пароль — придумайте
   и **запишите его**: он понадобится во всех следующих заданиях.
3. Создайте репозиторий: сверху перейдите в **Administration** (иконка
   шестерёнки) → **Repositories** → **Add Repositories** →
   **Local Repository** → выберите тип **Generic** → в поле Repository Key
   введите `myapp-local` → **Save**.
4. Проверьте из терминала, что репозиторий появился. ВПИШИТЕ свой пароль
   вместо `____`:

```bash
curl -u admin:____ http://localhost:8081/artifactory/api/repositories
```

## Результат

В списке есть `myapp-local` (`"type" : "LOCAL"`, `"packageType" : "Generic"`).
В отчёт: вывод команды.

> Заметьте: в списке уже был `example-repo-local` — это демонстрационный
> репозиторий из коробки.
