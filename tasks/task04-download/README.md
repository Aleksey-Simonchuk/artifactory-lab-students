# Задание 4. Скачивание и проверка целостности

**Цель:** скачать артефакт обратно (так делает сервер при деплое) и убедиться,
что файл не испортился.

## Шаги

1. Скачайте файл (выполняйте из папки `tasks/task03-upload`, ВПИШИТЕ пароль):

```bash
curl -u admin:____ -O \
  http://localhost:8081/artifactory/myapp-local/myapp/1.0.0/myapp-1.0.0.tar.gz
```

2. Посчитайте контрольную сумму скачанного файла:

```bash
shasum -a 256 myapp-1.0.0.tar.gz
```

3. Сравните её с полем `sha256` из JSON, который вернул сервер в задании 3.

## Результат

Суммы совпадают. В отчёт: вывод `shasum` и строка `sha256` из JSON
рядом (видно, что они одинаковые).

> Контрольная сумма — «отпечаток» файла: изменится хоть один байт,
> и сумма будет другой. Так проверяют, что файл не битый и не подменённый.
