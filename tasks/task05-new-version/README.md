# Задание 5. Выпуск новой версии

**Цель:** изменить приложение и опубликовать версию 1.0.1 рядом с 1.0.0.

## Шаги

1. В папке `tasks/task03-upload` измените приложение и номер версии:

```bash
echo "print('hello from myapp v1.0.1')" > myapp/main.py
echo "1.0.1" > myapp/VERSION
```

2. Откройте `upload.sh` и измените номер версии:

```bash
VERSION="1.0.1"
```

3. Запустите публикацию: `./upload.sh`
4. Посмотрите в интерфейсе (**Artifacts → myapp-local → myapp**):
   теперь там две папки — `1.0.0` и `1.0.1`.

## Результат

В отчёт: скриншот дерева с двумя версиями.

> Обратите внимание: версии лежат в разных путях и не затирают друг друга.
> А sha256 у них разные — содержимое же изменилось. Сравните суммы
> в ответах сервера.
