# Pro 5. Секреты: убираем пароль из скриптов

**Что делаем:** избавляемся от пароля в открытом виде в файлах.

**Зачем:** скрипт с паролем нельзя ни коммитить в git, ни показывать
коллегам. Пароль должен жить отдельно от кода.

## Способ 1. Переменная окружения

Поменяйте в своём `publish.sh` строку с паролем на:

```bash
PASSWORD="${ART_PASSWORD:?Задайте переменную ART_PASSWORD}"
```

Теперь скрипт не запустится без переменной. Запуск:

```bash
export ART_PASSWORD='ВАШ_ПАРОЛЬ'
./publish.sh 1.2.0
```

Пароль живёт в сессии терминала, а не в файле.

## Способ 2. Файл ~/.netrc

curl умеет сам брать логин/пароль из файла `~/.netrc`:

```bash
cat > ~/.netrc <<EOF
machine localhost
login admin
password ВАШ_ПАРОЛЬ
EOF
chmod 600 ~/.netrc
```

`chmod 600` обязателен: curl откажется читать файл, если он доступен
другим пользователям.

Теперь вместо `-u admin:пароль` можно писать просто `-n`:

```bash
curl -n http://localhost:8081/artifactory/api/repositories
```

## Задание

1. Переведите свой `publish.sh` на переменную окружения, проверьте
   запуск с `export` и ошибку без него.
2. Настройте `~/.netrc`, убедитесь, что `curl -n` работает.
3. Ответьте письменно: какой из способов выбрали бы для CI-сервера
   и почему?

## Результат

**В отчёт:** изменённую строку из publish.sh, вывод `curl -n`,
ответ на вопрос.
